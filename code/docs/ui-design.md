## 1. UI 设计范围

- 设计基准：**主流笔记本 1440 × 900（首要）**；以此为默认档，向上兼容外接屏、向下自适应到 1120
- 布局：主栏弹性 + 右栏定宽的双栏内容区；**`< 1152px` 时右栏下沉为单栏**（详见 5.2 断点表）
- 主题：**浅色 + 深色双主题**，同一套语义 token 切换，不做单独配色
- 出图范围：**UX 定义的 13 个页面全部出图**（PAGE-001 ~ PAGE-013），无「靠推导代替」的页面
- UI 不修改 `ux-design.md` 中已确认的流程、页面职责与交互逻辑

## 2. 设计图提示词（完整提示词）

```text
为「llm.wiki」——一个本地运行的个人知识库产品——生成一套 Web 界面设计稿。共 13 页，本次输出全部 13 页。

【产品背景】
用户把网页文章、PDF/论文、随手笔记三类素材喂进 raw/ 目录，LLM 自动把它们编译成互相 [[链接]] 的 markdown wiki 页面（实体页、概念页、来源摘要页），并按语义自动归类到分区。用户可以在界面上提问、浏览网络、定期体检。不使用向量数据库。

【整体风格】
专业冷静。像开发者每天都在用的工具，而不是营销页面：信息密度高但层次清楚，大量使用 1px 细边框和浅色分区，不靠阴影堆叠层次，不用渐变、不用玻璃拟态、不用大圆角按钮。参考气质：Obsidian 的克制 + Linear 的清晰。安静、精确、可信。

【设计基准与布局】
- 首要基准：主流笔记本 1440 × 900（除顶栏后可视高约 840）；内容容器最大宽 1360px 居中，左右各留 ~32px 呼吸位
- 顶部导航栏高 56px：左侧品牌 + 主导航（问答 / 浏览 / 图谱 / 素材库），右侧搜索框（可 Ctrl+K）+「待处理 N」提醒徽标 + 「喂素材」主按钮 + 当前主题标识
- 主内容区双栏：主栏（弹性，`min-width: 0`）+ 右侧栏 288px（上下文面板，可为空）
- 分区浏览页额外有左侧栏 240px（S 档转为横向滚动条，不隐藏）
- 自适应：≥1600 放宽容器与右栏；1152–1359 容器满宽、右栏收窄；≤1151 右栏下沉为单栏；表格类内容在该档改为横向滚动
- 行长限制：正文阅读区最宽 820px，任何断点下都不产生超长行

【色彩（必须严格遵守，浅深两套）】
浅色：主色 #2C6BED，强调色 #0E8E7E，页面底色 #FFFFFF，次级背景 #F6F7F9，卡片 #FFFFFF，分割线 #E2E6EB，正文 #171A1F，次要文字 #5B6470，弱化文字 #8B95A1，成功 #1A8759，警告 #A96500，危险 #C8382F
深色：主色 #5C93FF，强调色 #2BB8A3，页面底色 #14171B，次级背景 #191D22，卡片 #1B2026，分割线 #2A3138，正文 #E7EAEE，次要文字 #A2ABB6，弱化文字 #6F7883，成功 #3FBF87，警告 #D8962A，危险 #F2746B
强调色专用于 LLM 产出与运营数据；主色专用于交互与导航。不可混用。

【字体】
系统字体栈（system-ui / Segoe UI / 微软雅黑）。Display 28 · H1 22 · H2 18 · Body 15（行高 1.6）· Meta 13 · Caption 12；正文用 400，标题用 500。代码、文件路径、URL 用等宽字体 13px。

【组件规范】
- 按钮：高 34px（小号 28px），圆角 6px。主按钮实心主色；次级按钮白底细边框；幽灵按钮无边框
- 输入框：高 34px，浅灰底 + 细边框；聚焦时边框变主色并加 2px 柔和外圈
- 徽标：高 22px 胶囊形，用于页面类型（概念页 / 实体页）、状态（正常 / 待重编译 / 解析失败 / 已删除）、分区
- 卡片：圆角 12px，1px 边框，阴影极浅（0 1px 2px rgba(16,24,40,.05)）
- 表格行：高约 52px，行内 hover 变浅色，选中行背景为主色浅调
- 空状态：居中插画 + 一句引导 + 一个主行动按钮

【逐页要点】

PAGE-001 首页 · 问答台
```

## 5. 视觉设计规范

### 5.1 设计标准与可访问性基线

| 项 | 标准 |
|---|---|
| 正文对比度 | ≥ 7:1（浅色 #171A1F on #FFFFFF；深色 #E7EAEE on #14171B） |
| 次要文字对比度 | ≥ 4.5:1 |
| 触控 / 点击目标 | 可点击元素高度 ≥ 28px，主操作 ≥ 34px，相邻间距 ≥ 8px |
| 聚焦状态 | 2px 主色外圈 + 边框变色，键盘可达 |
| 色彩独立性 | 所有状态除颜色外均带文字标签，色盲可辨 |
| 链接识别 | 颜色 + 下划线双重区分 |

### 5.2 布局规范

**首要基准：主流笔记本 1440 × 900。** 顶栏 56px；间距体系 4 / 8 / 12 / 16 / 20 / 24 / 32 / 40 / 48；圆角 6px（控件）/ 12px（卡片）/ 48px（胶囊）。

**断点表**（实现在 `code/design/tokens.css`，`--container / --rail-w / --gutter` 三个 token 驱动全局）

| 档位 | 视口宽度 | 容器最大宽 | 右栏 | 左右内边距 | 布局行为 |
|---|---|---|---|---|---|
| XL | ≥ 1600px | 1520px | 312px | 40px | 外接屏 / 大屏：放宽容器，但正文仍受 820px 行长限制 |
| **L** | **1360 – 1599px** | **1360px** | **288px** | **32px** | **默认档，1440×900 落在此档，为设计与验收的首要基准** |
| M | 1152 – 1359px | 100%（满宽） | 256px | 24px | 小尺寸笔记本 / 半屏分屏：栏宽与间距同步收紧 |
| S | ≤ 1151px | 100%（满宽） | — | 20px | 单栏：右栏下沉到主内容下方，顶栏间距收窄，表格横向滚动 |

各档共同约束：

- 主栏 `flex: 1 1 auto` + `min-width: 0`，保证长标题、代码块与表格不撑破布局
- 右栏在 L / XL 档 `position: sticky`，顶距 `topbar + 24px`；S 档回落为静态块
- 正文阅读区（`.doc` / `.prose`）恒定 `max-width: 820px`，避免宽屏下的超长行
- 画布类（PAGE-006 图谱）高度随视口弹性：`clamp(440px, calc(100vh - 320px), 700px)`
- 搜索框 `width: clamp(216px, 22vw, 320px)`，随视口收缩但保留最小可读宽
- 低于 1120px 不再作为目标：本机信息密度工具场景，窗口再窄时优先减少分栏而非压缩内容

**重新出图方式：**

```powershell
# 目录：code/design
# 依赖：本机 Chrome 或 Edge（脚本内会优先使用 Chrome）
pwsh -File render.ps1
```

脚本分两轮跑：**基准轮**把 13 个页面按 1440×900 各出图（设计系统页单独加高画布），**自适应轮**把页面详情页在 1120 与 1680 两档各出一版，用于验证断点切换。

源码即设计稿：`code/design/tokens.css` 是唯一的设计 token 来源，每页一个 HTML 文件，通过 `?theme=light|dark` 切换主题。修改设计后重跑脚本即可得到新图，并把 `code/design/images/` 下的产物同步到 `code/docs/ui-design/`。

> **出图后必做的两项校验**（能抓住绝大多数低级错误）：
> 1. 同一页浅色与深色 PNG 的**字节数必须不同** —— 相同即说明该页 `<head>` 里漏了主题切换脚本。
> 2. 逐张打开确认无横向溢出、无内容被裁切；布局存疑时不要靠肉眼比对缩放后的截图，直接把元素 `getBoundingClientRect()` 写进 `document.title`，再用 `--dump-dom` 读出来。

## 8. UI 验收标准

| 编号 | 验收项 |
|---|---|
| UI-AC-001 | 浅色与深色主题下，正文与背景对比度均 ≥ 7:1，次要文字 ≥ 4.5:1 |
| UI-AC-002 | 所有状态徽标在两种主题下都可辨识，且不依赖颜色单独表意 |
| UI-AC-003 | 设计图中出现的页面编号、状态编号与 `ux-design.md` 完全一致，无新增页面 |
| UI-AC-004 | 同一组件（按钮、徽标、卡片、表格行）在不同页面中样式完全一致 |
| UI-AC-005 | 每张设计图都能在 **1440×900** 基准画布下完整呈现，无横向滚动、无内容截断 |
| UI-AC-006 | 设计图的 HTML 源码可通过 `render.ps1` 复现出同名同尺寸图片 |
| UI-AC-007 | 在 XL(1600+) / L(1360–1599) / M(1152–1359) / S(≤1151) 四档下均无横向滚动；S 档右栏正确下沉为单栏 |
| UI-AC-008 | 任何断点下正文行宽不超过 820px，不产生超长行 |
| UI-AC-009 | `tokens.css` 是唯一的布局尺寸来源，页面 HTML 中不出现容器/栏宽的硬编码像素值 |
| UI-AC-010 | UX 定义的 13 个页面**全部**有对应设计图，编号连续无缺号，且设计图数量与页面数量一一对应（UI-000 / UI-007 / UI-008 为非页面参考图，单独说明） |
