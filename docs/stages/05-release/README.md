# 阶段 5：发布阶段

## 目标
把开发成果以可交付的方式发布，并确保发布后的状态可验证。

## 人的工作
- 确认发布内容和发布时间点
- 检查编译、部署、配置和回滚是否齐全
- 审核发布说明与风险提示
- 发布后进行验证，确认功能与状态正常

## AI 可以协助的内容
- 生成发布说明
- 生成回滚建议
- 检查发布前遗漏项

## 必须产出的内容
- 编译产物
- 部署包
- 发布说明
- 回滚方案
- 发布后检查清单

## 检查清单
- 构建是否成功
- 依赖是否齐全
- 配置是否正确
- 发布说明是否完整
- 回滚方案是否可执行

## 输出示例

- 发布内容：
- 发布时间：
- 变更影响：
- 回滚方式：
- 发布后观察事项：
