# 阶段 4：测试阶段

## 目标
确保功能可用，并尽早发现问题。

## 人的工作
- 制定测试重点和关键路径
- 进行人工测试，确认功能是否满足目标
- 验证 AI 生成的测试用例是否覆盖正确场景
- 修复发现的问题，并重新回归验证

## AI 可以协助的内容
- 生成测试用例
- 检查边界条件
- 对照需求测试功能完整性
- 汇总测试结果

## 必须产出的内容
- 测试计划
- 功能测试清单
- AI 辅助测试建议
- 人工测试记录
- 已修复与待修复问题列表

## 检查清单
- 关键路径已测试
- 边界情况已覆盖
- 问题已准确记录
- 修复状态已更新
- 功能是否符合成功标准
