# LLM Wiki 的核心是让模型维护一个持久化的 markdown 知识库。知识编译只做一次，之后每次查询都复用已经整理

LLM Wiki 的核心是让模型维护一个持久化的 markdown 知识库。知识编译只做一次，之后每次查询都复用已经整理好的页面，而不是重新做向量检索。Karpathy 认为维护成本才是知识库失败的根本原因。
